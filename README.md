# Sportstech QA Command Dashboard

Dark ops console for the QA Automation Bot: live run, queue, persistent history, defects, Wrike links, regressions, signed ingest + SSE.

Generated by QA Automation Bot · Owner: Soumya Saurav Pattnaik

## Stack

- Next.js 15 App Router, React 19, Tailwind 4, TypeScript
- Local SQLite (`data/qa-command.sqlite`) via `better-sqlite3`
- `DEMO_MODE=1` seeds labelled demo fixtures (never faked as production)

## Real-time (Claude / Grokbot / Codex / Cursor / watcher)

Do **not** use `DEMO_MODE=1` if you want live suite data. Follow [`docs/REALTIME.md`](docs/REALTIME.md).

```bash
cd ~/qa-automation-bot/qa-dashboard
# .env.local: DEMO_MODE=0 + INGEST_SECRET=…
npm run db:migrate
npm run dev:real
# other terminal: backfill + hooks
cd ~/qa-automation-bot && python3 scripts/emit_event.py backfill
```

### Emit a signed event (producer)

```bash
# with the Next server running
INGEST_URL=http://127.0.0.1:3000/api/ingest \
INGEST_SECRET=demo-ingest-secret \
python3 producer/emit_event.py suite.progress \
  --run-id demo:run:live \
  --json '{"pct":70,"current_case":"Cart total DE"}'
```

On the Mac bot, store the real secret in Keychain item `qa-automation-bot-dashboard-ingest` and set `INGEST_URL` to the deployed `/api/ingest`. Hook `producer/emit_event.py` from `qa-watcher.sh` with a 3s timeout (fire-and-forget; failures append `logs/events-outbox.jsonl`).

Restart the watcher only when `logs/qa-run.lock` is absent:

```bash
launchctl kickstart -k gui/$(id -u)/de.sportstech.qa-watcher
```

## API

- `GET /api/runs` · `GET /api/runs/:id` · `GET /api/queue` · `GET /api/defects` · `GET /api/suites/:suite_key`
- `POST /api/ingest` — HMAC-SHA256 over `timestamp + "." + rawBody` (`X-QA-Timestamp`, `X-QA-Signature`)
- `GET /api/stream` — SSE, ≤55s, `retry: 3000`, resume via `Last-Event-ID`

## Deploy to Vercel (public URL for the team)

See [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md).

Production needs:

- `DATABASE_URL` — Postgres (Vercel / Neon)
- `INGEST_SECRET` — shared with Mac Keychain `qa-automation-bot-dashboard-ingest`
- `DEMO_MODE=0`
- `PUBLIC_READ=true`

Then point Mac agents at:

```bash
export INGEST_URL=https://<your-app>.vercel.app/api/ingest
```
